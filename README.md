Expense Tracker

A command-line expense tracker built in 30 days while learning Python and SQL. Data is stored in a SQLite database, with monthly reports and charts.

Goals
Learn Python basics: variables, loops, functions, files, classes
Learn SQL basics: SELECT, GROUP BY, JOIN, UPDATE, DELETE
Connect Python and SQLite with the sqlite3 module
Build a project I can show on GitHub
Project structure
expense-tracker/
├── data/sample_expenses.csv   # starter data
├── sql/schema.sql             # table definitions
├── sql/queries.sql            # saved queries
├── src/                       # main.py, database.py, models.py, reports.py
├── tests/                     # pytest tests
└── notebooks/analysis.ipynb   # pandas + matplotlib analysis
